# Cryptocurrency Portfolio Tracking

## When to Use
- Holdings are on multiple exchanges or wallets
- Need to monitor crypto performance across platforms
- Preparing for tax reporting

## Prerequisites
- Holdings on multiple exchanges or wallets
- Internet access

## Core Process

### 1. Select Tracking Platform

| Platform | Features |
|----------|----------|
| CryptoCompare (www.cryptocompare.com) | Basic portfolio tracking |
| Cointracker (www.cointracker.io) | Includes tax add-on |
| Coinstats | Portfolio tracking |

### 2. Data Input Method

**Manual Entry**
- Manually input what has been bought
- Suitable for smaller portfolios

**Automated Import**
- Cut and paste a code from the exchange
- Connect an API from each exchange (e.g., Binance, Coinbase, Kraken)
- Suitable for larger portfolios with frequent trading

### 3. System Processing
The system automatically:
- Tracks fluctuations of all coins on a daily basis
- Amalgamates several positions of the same coin into a single holding
- Calculates the average price of the holdings

### 4. Tax Management (Cointracker specific)
- Use the tax add-on to calculate taxes automatically
- Allow accountant access to review taxes before approval

## Output
Unified dashboard showing:
- Total portfolio value
- Daily fluctuations
- Average prices
- Tax calculations (if using Cointracker)
