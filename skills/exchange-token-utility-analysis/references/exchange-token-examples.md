# Exchange Token Examples

## Major Exchange Tokens

### Binance Coin (BNB)
- **Exchange**: Binance
- **Primary Utility**: 25% fee discount (originally), now reduced to tiered discounts
- **Additional Uses**: BNB Chain gas fees, Binance Card payments, token sales participation
- **Burn Mechanism**: Quarterly burns based on trading volume

### Huobi Token (HT)
- **Exchange**: Huobi (now HTX)
- **Primary Utility**: Fee discounts for trading on Huobi
- **Additional Uses**: Voting rights, VIP tier upgrades
- **Buyback Program**: Quarterly buybacks using 20% of exchange revenue

### KuCoin Shares (KCS)
- **Exchange**: KuCoin
- **Primary Utility**: Fee discounts (up to 30%)
- **Additional Uses**: Daily dividend payouts from trading fees
- **Burn Mechanism**: Ongoing buyback and burn program

### Other Notable Examples
- **Bitpanda Ecosystem Token (BEST)**: Bitpanda exchange utility
- **GateToken (GT)**: Gate.io exchange token
- **OKB**: OKX exchange utility token

## Fee Discount Tiers

Most exchanges implement tiered discount structures based on token holdings:

| Holding Amount | Typical Discount Range |
|----------------|----------------------|
| Minimal (< $100) | 0-5% |
| Moderate ($100-$1,000) | 5-15% |
| High ($1,000-$10,000) | 15-25% |
| Very High (>$10,000) | 25-30% |

*Note: Actual tiers vary by exchange and may change over time.*

## Value Correlation Factors

1. **Trading Volume**: Higher volume = more fee discounts used = higher token demand
2. **User Growth**: More users = increased token adoption
3. **Market Conditions**: Bull markets amplify exchange activity and token value
4. **Regulatory Environment**: Exchange regulations impact token utility and value

## Risk Considerations

- **Exchange Risk**: Token value tied to single exchange's success
- **Regulatory Risk**: Utility tokens may face securities classification
- **Centralization Risk**: Exchange controls token supply and utility
- **Liquidity Risk**: Limited trading venues outside issuing exchange
