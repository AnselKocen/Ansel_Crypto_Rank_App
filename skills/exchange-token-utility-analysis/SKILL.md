# Exchange Token Utility Analysis

## When to Use This Skill
Apply this skill when:
- Evaluating a cryptocurrency native to a specific exchange ecosystem
- Analyzing fee discount structures for exchange tokens
- Assessing the value proposition of utility tokens like BNB, HT, KCS, or similar
- Comparing benefits across different exchange-issued tokens
- Determining whether holding an exchange token provides meaningful utility

## Core Evaluation Workflow

### 1. Identify Token Type
Confirm the token is a utility token specific to an exchange ecosystem:
- Token is issued by a centralized exchange
- Primary utility is tied to exchange operations
- Token cannot be used outside the issuing exchange's ecosystem

### 2. Analyze Usage Mechanics
Evaluate how the token functions within the exchange:
- **Fee Reductions**: Determine the discount percentage applied to trading fees when holding the token
- **Service Payments**: Identify which exchange services can be paid for using the token
- **Staking Requirements**: Check if staking is required to unlock benefits

### 3. Assess Accessibility Constraints
Document ecosystem limitations:
- Token can only be used on the specific issuing exchange
- Purchase must occur on that exchange (not available on external markets)
- Withdrawal restrictions or lock-up periods may apply

### 4. Evaluate Value Proposition
Analyze the correlation between token value and exchange performance:
- **Exchange Popularity**: Measure user base size and trading volume
- **Network Effect**: Assess how exchange growth impacts token demand
- **Tokenomics**: Review supply, burn mechanisms, and distribution

### 5. Compare Competitive Landscape
Benchmark against similar exchange tokens:
- Identify competing exchanges with similar utility tokens
- Compare fee discount rates and additional benefits
- Evaluate relative market position and adoption

## Key Variables to Analyze

| Variable | Type | Description |
|----------|------|-------------|
| Exchange_Popularity | Metric | User base size and trading volume of the issuing exchange |
| Fee_Rate | Percentage | Trading cost discount applied when holding the token |
| Token_Supply | Number | Total and circulating supply of the token |
| Burn_Rate | Percentage | Rate at which tokens are removed from circulation |

## Output Format
Provide a value assessment that includes:
- Primary utility functions (fee discounts, service payments)
- Ecosystem constraints and limitations
- Correlation with exchange popularity
- Competitive positioning
- Overall value proposition summary

**Result Template:** Token value is derived from exchange utility and popularity; primarily used for fee discounts.
