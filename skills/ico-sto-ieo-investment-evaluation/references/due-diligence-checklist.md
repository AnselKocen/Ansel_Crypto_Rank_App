# Due Diligence Checklist

## Team Evaluation
- [ ] LinkedIn profiles verified
- [ ] Previous crypto experience confirmed
- [ ] BitcoinTalk.org sentiment checked
- [ ] Developer responsiveness tested

## Idea Validation
- [ ] Real problem identified
- [ ] Hungry market exists
- [ ] Unique value proposition
- [ ] Better than competitors

## Token Utility
- [ ] Specific purpose identified
- [ ] Not replaceable by BTC/ETH

## Financial Structure
- [ ] Cap type identified (Hard/Open)
- [ ] Fund allocation transparent
- [ ] Development budget adequate

## Distribution
- [ ] Team allocation <50%
- [ ] Distribution linked to roadmap
- [ ] Saturation risk assessed
- [ ] Incentives verified
