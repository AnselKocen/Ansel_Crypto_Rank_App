# Ripple 支付网络协议

## 概述
Ripple 于 2012 年推出，是兼具数字货币 XRP 与数字支付网络的双功能技术，旨在让国内及国际银行转账更快、更便宜。

## 适用场景
在以下情况下应用本协议：
- 促进国际银行转账
- 寻求替代或补充 SWIFT 基础设施
- 实现跨境支付解决方案
- 探索传统银行结算系统的替代方式
- 理解金融机构使用的加密货币支付网络

## 核心架构

### 平台类型
- 开源、点对点的去中心化平台
- 支持转移任意形式的货币，包括法定货币与加密货币
- 使用共识协议进行验证，而不是工作量证明

### 关键组件

#### 网关系统
- 充当各方之间的信用中介
- 作为连接环节，向公共地址接收和发送货币
- 支持网络参与者建立信任关系
- 与纯粹的 P2P 加密货币不同，依赖这些中介网关

#### 共识协议
- 验证账户余额与交易
- 替代工作量证明挖矿
- 实现快速交易确认
- 无需高能耗挖矿即可维护网络完整性

## 交易流程

1. **发起**：用户通过网关发起付款
2. **货币兑换**：网关协助在任意货币之间兑换，例如 USD 换成 Bitcoin
3. **验证**：共识协议验证交易
4. **结算**：交易在数秒内完成，费用很低

## 性能特征
- 交易时间：数秒
- 费用：即使交易量很大，也保持很低
- 可扩展性：面向机构的大规模使用而设计
- 结算：与传统银行相比，接近即时完成

## 限制与注意事项
- 需要网关中介，并非纯粹 P2P
- 依赖网关参与及信任关系
- 不同于传统工作量证明区块链
- 主要面向机构与金融机构使用
