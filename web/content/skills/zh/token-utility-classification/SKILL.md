# 代币用途分类

## 适用场景
在以下情况下使用本知识：
- 分析首次代币发行（ICOs）中的代币
- 评估证券型代币发行（STOs）中的代币
- 审查首次交易所发行（IEOs）中的代币
- 判断区块链代币的监管分类或金融性质

## 前提条件
- 初创企业或公司正在发行代币
- 发行公司有明确的目标与文档
- 理解代币预期的使用场景

## 分类流程

### 第 1 步：确定代币是否代表公司产品
检查代币是否具有以下功能：
- 项目生态内部的交换媒介
- 可兑换特定数量公司产品或服务的单位
- 项目平台内的交易工具

**如果是**：归类为**产品型代币**。

### 第 2 步：确定代币是否代表利润分享权
检查代币是否具有以下功能：
- 公司所有权份额，类似传统股票
- 获得一定比例公司利润的权利
- 对公司决策的投票权或治理权

**如果是**：归类为**利润分享型代币**。

### 第 3 步：确定代币是否代表公司债券
检查代币是否具有以下功能：
- 向发行公司提供的贷款
- 收取利息的权利
- 具有预设利率的债务工具

**如果是**：归类为**公司债券型代币**。

## 重要说明
- 代币角色由公司声明的目标决定，不一定与市场认知相同
- 除非传统金融工具已被代币化，否则本分类不适用于它们
- 一个代币可能同时具有多个类别的特征，应根据公司文档，优先按其主要功能分类

## 输出格式
使用以下格式给出分类结果：

```
The token represents [Role Name] based on the company's goals
```

其中，`[Role Name]` 为以下类别之一：
- **产品型代币（Product Token）**：交换媒介
- **利润分享型代币（Profit Sharing Token）**：所有权工具
- **公司债券型代币（Corporate Bond Token）**：债务工具
