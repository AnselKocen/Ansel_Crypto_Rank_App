# 加密货币投资策略与尽职调查

## 适用场景
以下情况适用：
- 制定加密货币投资策略
- 评估潜在加密货币投资
- 对新项目开展尽职调查
- 识别潜在投资中的风险信号
- 解释通过加密货币获得收入的不同方式

## 获得收入的方式

### 1. 挖矿

#### 工作量证明（PoW）
- **过程**：使用算力验证区块链交易
- **奖励**：获得 Bitcoin 或其他币种
- **要求**：能源消耗高，需要解决复杂难题
- **盈利能力**：普通人的获利空间有限，因为竞争激烈、成本较高

#### 权益证明（PoS）
- **过程**：通过质押代币获得投票权
- **奖励**：获得交易手续费和区块奖励
- **优势**：降低能源消耗
- **规模关系**：持币越多，权重越大

### 2. 借贷
- **过程**：交易者借用你的代币进行保证金或杠杆交易
- **回报**：借款人归还代币，并支付一定比例的佣金
- **风险**：违约风险、平台风险
- **平台**：有多种加密货币借贷平台可供使用

### 3. 购买成熟加密货币
- **过程**：购买 Bitcoin 或 Ethereum 等现有资产
- **策略**：长期持有或主动交易
- **风险**：市场波动、监管风险
- **示例**：BTC、ETH、主要山寨币

### 4. 购买新发行项目（ICO/IEO/STO）

#### 类型
- **ICO**（首次代币发行）：直接面向投资者
- **IEO**（首次交易所发行）：通过交易所进行
- **STO**（证券型代币发行）：受监管的证券型代币

#### 潜在回报
- 可能获得高回报（例如 £1,000 → £10,000-£100,000）
- 可能在较短时间内实现
- **风险**：极高，且存在大量骗局

## 尽职调查：应避开的风险信号

### 1. “模仿型”币种
- **信号**：功能与现有币种完全相同，没有额外优势
- **做法**：避开
- **例外**：如果相较现有方案显著更好、更快或更便宜，可考虑

### 2. 特定行业币种
- **信号**：只针对某个市场设计的币种（例如用于大麻行业的 Potcoin）
- **理由**：如果通用币种（Bitcoin、Monero、Ethereum）已经能解决问题，就没有真正的必要另造币种
- **做法**：避开缺乏明显优势的单一用途币种

### 3. 团队评估
- **风险信号**：团队过小或能力不足
- **要求**：
  - 拥有落实白皮书所需的相关经验
  - 团队规模足以完成项目
  - 必要时有招聘计划
- **做法**：避开单人团队或缺乏经验的团队

### 4. 交易量分析
- **风险信号**：交易量低，买方或卖方数量不足
- **要求**：随着市场成熟，应观察到交易量持续增长
- **风险**：交易量低意味着流动性差，难以退出仓位
- **做法**：避开低交易量币种

## 尽职调查清单

### 白皮书审阅
- [ ] 问题与解决方案表述清楚
- [ ] 技术可行
- [ ] 路线图与里程碑切合实际
- [ ] 代币用途定义明确

### 团队背景
- [ ] 具备区块链或技术领域的相关经验
- [ ] 有成功项目记录
- [ ] 团队成员资料透明
- [ ] 团队规模适合项目范围

### 市场分析
- [ ] 目标市场与用途清楚
- [ ] 相比现有方案有竞争优势
- [ ] 交易量增长
- [ ] 社区有参与度和支持

### 技术评估
- [ ] 有可运行产品或 MVP
- [ ] 有代码审计结果
- [ ] 已落实安全措施
- [ ] 考虑扩展性

## 风险管理
- 在不同策略之间分散配置
- 投资金额不得超过承受损失的能力
- 先从成熟加密货币开始，再考虑新发行项目
- 对所有投资开展充分尽职调查
- 为高波动和可能全部损失做好准备
