# 加密货币投资组合跟踪

## 适用场景
- 持仓分散在多个交易所或钱包
- 需要跨平台监控加密资产表现
- 准备税务申报

## 前提条件
- 在多个交易所或钱包中持有资产
- 能够访问互联网

## 核心流程

### 1. 选择跟踪平台

| 平台 | 功能 |
|----------|----------|
| CryptoCompare（www.cryptocompare.com） | 基础投资组合跟踪 |
| Cointracker（www.cointracker.io） | 包含税务附加功能 |
| Coinstats | 投资组合跟踪 |

### 2. 数据录入方式

**手动录入**
- 手动输入已购买的资产
- 适用于较小的投资组合

**自动导入**
- 从交易所复制并粘贴一段代码
- 连接各交易所的 API（如 Binance、Coinbase、Kraken）
- 适用于交易频繁、规模较大的投资组合

### 3. 系统处理
系统会自动：
- 每日跟踪所有币种的价格波动
- 将同一币种的多笔仓位合并为单一持仓
- 计算持仓平均价格

### 4. 税务管理（Cointracker 专属）
- 使用税务附加功能自动计算税额
- 授权会计师在批准前审阅税务数据

## 输出结果
统一看板展示：
- 投资组合总价值
- 每日波动
- 平均价格
- 税额计算（使用 Cointracker 时）
