# ICO／STO／IEO 投资评估

## 适用场景
- 区块链初创企业寻求融资
- 投资者打算参与加密货币众筹销售
- 评估是否投资加密货币初创企业

## 前提条件
- 持有具备流动性的加密货币，例如 Bitcoin、Ether
- 能够阅读和评估技术白皮书
- 能承受高风险、缺少监管的投资

## 风险评估
- 存在本金全部损失的高风险
- ICO 和 IEO 缺少监管，使追回资金十分困难
- 项目处于非常早期的阶段
- 绝不投入无法承受全部损失的资金

## 识别融资模式

| 模式 | 监管情况 | 说明 |
|-------|------------|-------------|
| **ICO**（首次代币发行） | 未受监管 | 以未来的加密货币换取当下有流动性的加密货币，例如 BTC、ETH；发生在区块链上线之前。 |
| **STO**（证券型代币发行） | 受监管 | 最接近 IPO。证券型代币代表公司所有权，例如 1% 的代币 = 1% 的所有权。比 IPO 更快，但需要类似监管。 |
| **IEO**（首次交易所发行） | 未受监管 | 由 Binance 等交易所通过自身平台发行币种。投资者依赖交易所的尽职调查，但个人研究仍然至关重要。 |

## 资产分类

### 原生币
- 用于转移货币价值的原生加密货币，例如 Bitcoin
- 单纯用于价值储藏或数字货币
- 主要用途有限，通常为价值转移或储存

### 代币
- 能够存储复杂、多方面数据流的资产
- 通常存在于 Ethereum 区块链系统中
- 通过智能合约系统创建
- 具有高度可编程性和多种功能
- 应根据商业模式与潜在解决方案进行评估

## 白皮书评估
确认项目拥有白皮书，并详细说明：
- 技术打算如何运作
- 代币设计、获取方式与用途
- 具体解决什么问题，以及解决机制是什么
- 代币如何被用于解决该问题，这对投资者价值至关重要

## 全面尽职调查框架

### 1. 团队评估：经验与声誉
- 阅读白皮书，并在 LinkedIn 上分析创始成员与团队资料
- 核实其行业经历和具体加密项目经验，包括过去的项目、ICO 及影响
- 访问 BitcoinTalk.org，了解资深投资者的看法，留意“scam”等表示诈骗的关键词
- 检查开发者是否回避问题或缺少协作
- 发送私人消息，测试回应情况
- **决策点**：如果根据团队经验判断其无法交付，不再继续

### 2. 创意验证：问题与市场
- 判断创意是否解决真实问题，以及是否存在需求强烈的潜在市场
- 评估项目是否为世界带来独特价值
- 检查是否只是跟风产品，没有比现有方案显著改善
- **决策点**：除非公司能比竞争对手做得好得多，否则不要投资

### 3. 代币用途分析
- 确定新增专用代币的具体目的
- **关键问题**：为什么 Bitcoin 或 Ethereum 不足以满足这个项目的需求？

### 4. 财务结构与募资上限
- **上限分析**：警惕无限制或开放式募资上限；无限融资会使代币更不稀缺，需求更低
- **资金分配**：确认资金去向透明，包括开发预算 %、营销预算 % 及其他分配

### 5. 代币价值与分配
- **价值评估**：评估当前价值是否值得，以及是否具备增长潜力
- **饱和度检查**：判断发行代币是否过多，会不会使市场饱和
- **激励机制**：确认是否有使用代币的真实激励
- **分配计划**：检查团队份额；团队获得 >50% 的份额是可疑的贪婪信号
- **路线图关联**：确保分配与项目阶段或里程碑挂钩，例如测试版本发布

## 实际执行步骤
1. 初创企业宣传初始代币供应的销售
2. 投资者阅读白皮书，用 Bitcoin 或 Ether 换取新代币
3. 初创企业将收到的 Bitcoin 或 Ether 兑换为法定货币，用于技术开发和各项成本
4. 如果项目成功上线并获得采用，新货币的价值上升，投资者便有机会获利
