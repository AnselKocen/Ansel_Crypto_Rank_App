# 交易所代币示例

## 主要交易所代币

### Binance Coin（BNB）
- **交易所**：Binance
- **主要用途**：最初为 25% 手续费折扣，后来缩减为分级折扣
- **其他用途**：BNB Chain 的 Gas 费用、Binance Card 支付、参与代币销售
- **销毁机制**：依据交易量按季度销毁

### Huobi Token（HT）
- **交易所**：Huobi，现为 HTX
- **主要用途**：在 Huobi 交易时获得手续费折扣
- **其他用途**：投票权、VIP 等级升级
- **回购计划**：使用交易所收入的 20% 按季度回购

### KuCoin Shares（KCS）
- **交易所**：KuCoin
- **主要用途**：手续费折扣，最高 30%
- **其他用途**：每天从交易手续费收入中分红
- **销毁机制**：持续回购与销毁计划

### 其他值得关注的示例
- **Bitpanda Ecosystem Token（BEST）**：用于 Bitpanda 交易所生态
- **GateToken（GT）**：Gate.io 交易所代币
- **OKB**：OKX 交易所实用型代币

## 手续费折扣等级

大多数交易所根据代币持有量实施分级折扣：

| 持有金额 | 典型折扣范围 |
|----------------|----------------------|
| 少量（< $100） | 0-5% |
| 适量（$100-$1,000） | 5-15% |
| 较多（$1,000-$10,000） | 15-25% |
| 非常多（>$10,000） | 25-30% |

*注意：实际等级因交易所而异，也可能随时间变化。*

## 价值相关因素

1. **交易量**：交易量越高 = 更多人使用手续费折扣 = 代币需求越高
2. **用户增长**：用户越多 = 代币采用程度提高
3. **市场环境**：牛市会放大交易所活动与代币价值
4. **监管环境**：交易所监管会影响代币用途和价值

## 风险考虑

- **交易所风险**：代币价值与单一交易所的成败挂钩
- **监管风险**：实用型代币可能被认定为证券
- **中心化风险**：交易所控制代币供应和用途
- **流动性风险**：发行交易所以外的交易场所有限
