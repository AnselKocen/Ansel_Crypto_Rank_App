# ICO／STO／IEO 投资执行

## 适用场景
在以下情况下使用本知识：
- 已完成对加密货币项目的尽职调查
- 已作出投资决定
- 需要执行 ICO、STO 或 IEO 交易
- 需要钱包设置与资金转移流程的指导

## 前提条件
- 已完成对目标项目的尽职调查
- 有可用于投资的法定货币
- 已确定所选的 ICO／STO／IEO 项目

## 执行流程

### 1. 获取所需的加密货币
- 将法定货币兑换为所需加密货币，通常为 Bitcoin 或 Ethereum
- 确保资金足以覆盖投资金额与交易手续费
- 注意：初创企业之后会将这些加密货币换回法定货币，以支付运营成本

### 2. 设置在线钱包
- 创建在线钱包，例如位于 https://metamask.io/ 的 MetaMask
- **关键要求**：不要直接使用交易所钱包
- 许多交易所会阻止向 ICO 初创企业转账
- 确保钱包已妥善保护并完成备份

### 3. 向初创企业转移资金
- 发送初创企业指定的加密货币
- 使用该企业提供的准确钱包地址
- 发送前再次核对地址，因为加密货币交易不可逆
- 在区块链上核实交易确认状态

### 4. 投后参与
- **主动跟踪**：关注开发进度，参与社区并推广项目
- **建立联系**：参加会议，与团队见面，获取白皮书未提供的见解
- **协商**：利用关系争取预售折扣，例如提及曾在会议上见面，以降低最低 ETH 投资要求
- **分散投资**：由于成功与否高度投机且难以预测，将风险分散至多项投资；原资料建议参与 30+ 个 ICO

## 关键限制
- 大多数初创企业不直接接受来自交易所账户的加密货币
- 投资高度投机且难以预测
- 始终使用个人在线钱包，切勿直接从交易所转出
- 加密货币交易不可逆，发送前应核实所有细节

## 必需变量
- `crypto_type`：所需加密货币，通常为 Bitcoin 或 Ethereum
- `wallet_source`：你的个人在线钱包地址，不是交易所钱包
- `target_address`：初创企业提供的特定钱包地址
