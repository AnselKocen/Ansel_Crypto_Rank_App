# 加密货币购买与交易所选择

## 适用场景
- 执行加密货币买单
- 首次选择交易平台
- 决定使用哪家交易所完成法币与加密货币或加密货币之间的交易

## 前提条件
- 银行账户
- 身份证明文件（ID）

## 核心流程

### 1. 应用储备货币规则
先使用法定货币购买 Bitcoin 或 Ethereum，再用 BTC/ETH 购买其他山寨币。

### 2. 选择交易所类型

**选项 A：法币交易所**（如 Coinbase、Gemini）
- 功能：使用法币（USD、Euro、GBP）买卖加密货币
- 流程：开户、核验身份、用法币兑换 Bitcoin

**选项 B：币币交易所**（如 Binance、Kraken）
- 功能：连接买方与卖方，并收取交易手续费
- 用法：将 BTC 从法币交易所转入这里，以购买山寨币

### 3. 评估选择标准

| 标准 | 考量因素 |
|----------|---------------|
| **声誉** | 查看专业交易者及行业网站的评价 |
| **费用** | 了解充值、交易和提现费用（Coinbase Pro 的费用低于标准 Coinbase） |
| **支付方式** | 信用卡或借记卡：需要身份核验，费用较高；银行电汇：时间较长，受银行处理时间影响 |
| **身份核验** | 多数美国和英国平台要求在充值或提现时核验身份，以满足反洗钱要求；可能需要数天 |
| **汇率** | 不同交易所的汇率不同，差异可达 10% 或更高；应多方比较 |

### 4. 常见交易所示例
- **Kraken**：规模大、安全，并持有银行牌照
- **Binance**：全球规模最大、交易对最多、交易手续费最低

## 限制条件
- 开户流程表面简单，但实际并不容易，对初学者可能较为繁琐
- 必须先买 BTC/ETH 作为“储备货币”，才能购买其他山寨币
