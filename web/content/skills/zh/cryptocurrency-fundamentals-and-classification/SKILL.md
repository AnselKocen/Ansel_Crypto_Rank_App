# 加密货币基础与分类

## 适用场景
- 评估某项资产作为货币的适用性或有效性
- 对加密货币资产分类
- 分析首次代币发行（ICO）
- 理解原生币与代币的区别

## 前提条件
- 理解价值和交换等基础经济概念
- 了解区块链技术
- 理解开源代码

## 评估货币类型的 5 项特征

从以下 5 项特征比较资产：

### 1. 稀缺性（供应限制）
| 资产 | 是否稀缺 | 说明 |
|-------|----------|-------------|
| 法定货币 | 否 | 政府可以每天继续印钞；供应增加时价值下降 |
| 黄金 | 是 | 价值来自稀缺性；开采难度上升，供应逐渐耗尽 |
| 比特币 | 是 | 硬性上限为 21 million 枚，不能继续增发 |

### 2. 可分割性（拆分为更小金额的能力）
| 资产 | 是否可分割 | 说明 |
|-------|----------|-------------|
| 法定货币 | 是 | 容易分割 |
| 黄金 | 否 | 难以分割用于小额交易，例如支付一杯茶的费用 |
| 比特币 | 是 | 可高度细分；一“聪”等于一枚比特币的一亿分之一 |

### 3. 可转移性（转移的便利程度）
| 资产 | 是否易于转移 | 说明 |
|-------|--------------|-------------|
| 法定货币 | 是，但有条件 | 可通过电子系统转移，但成本高、速度慢 |
| 黄金 | 否 | 难以大量运往海外 |
| 比特币 | 是 | 可像数字文件一样发送到另一个钱包，几分钟内完成，费用仅为传统方式的一小部分 |

### 4. 耐久性（抵御磨损或损坏的能力）
| 资产 | 是否耐久 | 说明 |
|-------|---------|-------------|
| 法定货币 | 部分 | 硬币耐用，但纸币不耐用；需要定期印制新纸币 |
| 黄金 | 是 | 非常耐久 |
| 比特币 | 是 | 一枚比特币无法被毁坏 |

### 5. 可识别性（接受与验证）
| 资产 | 可识别性 | 说明 |
|-------|-------------|-------------|
| 法定货币 | 不一 | 在发行国可被接受；在国际上不能直接使用，需要兑换；容易被伪造 |
| 黄金 | 不一 | 部分国家偏好其安全性；验证难点在于难以确认收到的黄金是否真实 |
| 比特币 | 不一 | 有钱包即可持有；但当前多数商店尚不接受；无法复制或伪造 |

## 分类：原生币与代币

### 判断流程

1. **分析资产起源与代码库**：
   - 是否为比特币开源代码的变体？
   - 是否运行在自己的原生区块链或其分叉上？

2. **如果是**：归类为**原生币（或山寨币）**
   - **用途**：作为简单的价值储藏手段或数字货币
   - **功能**：主要局限于单一用途，即价值转移或储藏，不能在其上构建复杂应用
   - **示例**：Litecoin、Dogecoin、Bitcoin Cash、Bitcoin Gold
   - **市场术语**：发行活动称为“ICO”

3. **如果不是，属于次级资产**：归类为**代币**
   - **生态系统**：通常存在于 Ethereum 区块链系统或类似的可编程区块链中
   - **目的**：用于运行特定去中心化应用（DApp）的次级资产
   - **生成方式**：由智能合约系统（SCS）创建
   - **用途**：高度可编程，具备多种功能，可承载复杂、多层次的价值
   - **示例**：GNT（Golem）、GNO（Gnosis）
   - **市场术语**：发行活动称为“代币发行”

### 区别概述
- **原生币** = 简单的货币或价值储藏工具（Bitcoin 产生原生币）
- **代币** = 用于复杂应用的可编程资产（Ethereum 产生代币）

## 限制条件
- 不适用于无意作为交换媒介或价值储藏手段的资产
- 原生币与代币的区别取决于技术架构和用途，而非市值或价格
